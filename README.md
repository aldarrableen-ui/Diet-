# LeanWell — Sep 28 to Nov 20, 2026

A mobile-first React + TypeScript fat-loss tracker with **54 explicit calendar days**.

## Run
1. Install Node.js 20+
2. `npm install`
3. `npm run dev`

## Included
- Onboarding + maintenance/macro estimate
- 54 explicit daily meal/workout records (no 7-day repeat object)
- No eggs, salmon, oats, cottage cheese, or plain tuna
- Meal 1 is protein-forward without major starch sources
- 5 training days/week + recovery pages
- Warm-up, strength, cardio, cool-down
- Progressive-overload guidance and set checkboxes
- Steps, water, weight, sleep fields
- Meal swaps/regenerate interaction
- "I ate something else" + restaurant logging
- Weekly grocery view
- Calendar and localStorage persistence
- Weekly check-in, measurements, photo placeholders

This is a client-side starter architecture. Nutrition values are estimates and should be verified against actual brands/labels. Restaurant estimates are inherently approximate.
